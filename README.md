## 📦 作品

### 大屏屏幕适配库 <code>@thisiszas/bigscreen-board</code>

数据大屏屏幕适配库：把固定设计稿等比投影到任意分辨率屏幕，支持等比（scale）/ 拉伸（stretch）双适配模式、背景 cover 自适应延展。零依赖（仅 peer 依赖 vue），不捆绑 echarts / 字体。
