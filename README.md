### 🏡 岛上工坊

#### 📦 大屏屏幕适配库 · `@thisiszas/bigscreen-board`

把固定设计稿等比投影到不同分辨率的屏幕，让每块数据大屏都找到合适的尺寸。

- **两种适配方式**：等比缩放（scale） / 拉伸（stretch）。
- **背景自然延展**：支持 cover 自适应。
- **轻装上岛**：零依赖，仅 peer 依赖 Vue，不捆绑 ECharts 或字体。
